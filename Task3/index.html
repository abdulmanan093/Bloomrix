4. Code Examples

Press Ctrl + S to save your HTML file.

Minimal HTML page example:

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
  </body>
</html>

Expected output in the browser heading: Hello, World!
